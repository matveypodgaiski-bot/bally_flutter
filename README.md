# Баллы - Flutter приложение

Приложение для учёта баллов за задания и покупок.

## Запуск

```bash
# Установить зависимости
flutter pub get

# Запустить на эмуляторе/устройстве
flutter run

# Собрать APK для Android
flutter build apk --release
```

## Структура

- `lib/models/` - модели данных
- `lib/providers/` - управление состоянием
- `lib/screens/` - экраны приложения
- `lib/widgets/` - переиспользуемые виджеты
